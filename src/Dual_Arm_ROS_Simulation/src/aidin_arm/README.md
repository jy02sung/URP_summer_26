# Aidin-arm Gazebo Simulation Code

## Quick Start

Gazebo:

    roslaunch aidin_arm gazebo.launch

Command node:

    rosrun aidin_arm arm_command
    rosrun aidin_arm mobile_command
    rosrun aidin_arm aruco_detection_command

Rviz node:

    roslaunch aidin_arm detector.launch

## Dependency

Eigen version 3.4.0 recommand
